# UI/UX Brief: Ibragimov Clinic (демо v2 «Цифровая клиника»)

## 1. Концепция
Клиника как цифровая лаборатория: кинематографичная тёмно-зелёная подача, крупная редакционная типографика (Cormorant + Montserrat), золотые линии-«волны», интерактивные объяснялки вместо каталога. Структура строится от проблемы пациента («Вам сказали: мало кости?», «Что вас беспокоит?»), а не от списка услуг.
Аудитория: пациенты 25–65, преимущественно с телефона (mobile-first), выбирают клинику для имплантации: важны доверие, цены, снятие страха.
Реальных фото пока нет: визуал держится на авторских SVG (челюсть, разрез кости, одонтограмма) и типографике.

## 2. Токены (`globals.css`, `@theme`)
night `#07201D`, forest `#0D332E`, pine `#14463F`, brand `#1D685D`, mint `#A8D5C5`, ivory `#F5F0E6`, paper `#FAF7F0`, sand `#E9DFCA`, gold `#C9A45C`, ink `#15211F`.
Радиусы: карточки 28–40px, кнопки pill. Контейнер 1280px. Зерно (SVG noise), стекло (`glass`).

## 3. Типографика
Display: Cormorant (variable, кириллица, курсив для акцентных слов, цифры lining). UI/текст: Montserrat. Заголовки `display-xl/lg/md` на clamp.

## 4. Структура главной
Hero с анимированной челюстью → бегущая строка → pinned-история про кость → навигатор ситуаций → конструктор плана (одонтограмма + расчёт «от») → горизонтальный «цифровой путь» → доктор → оборудование (bento) → цены (плитки) → рейтинги + лента отзывов → финальная форма и контакты.

## 5. Навигация
Минимальная плавающая шапка (лого, телефон, «Записаться», «Меню») + полноэкранное меню; на мобильном нижний док (Позвонить, WhatsApp, Подобрать, Записаться). Страница услуги: боковой sticky-рельс оглавления.

## 6. Движение
Split-text, reveal, count-up, magnetic-кнопки, marquee, pinned scroll-stories (CSS sticky + `useScroll`), параллакс героя. При `prefers-reduced-motion` включаются статичные раскладки.

## 7. Состояния и доступность
Формы: inline-валидация, loading, success (демо без отправки), согласие не предзаполнено. Одонтограмма — кнопки с aria-pressed и клавиатурой. Контраст ≥ 4.5:1 для текста.

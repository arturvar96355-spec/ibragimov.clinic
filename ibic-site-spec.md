# IBIC (ibic.clinic) — разбор сайта для пересборки

> Документ для Claude Code. Источник: https://ibic.clinic/ (осмотр 17.10.2026, десктоп 1359px).
> Цель: сделать новый сайт с той же структурой и контентом, но на современном стеке и без багов/мусора старого.
> Картинки: см. раздел 10 и скрипт `scrape-assets.mjs` (лежит рядом с этим файлом).

## 0. Кратко

- Стоматологическая клиника в Москве, ЮЗАО. Бренд на сайте двоится: **International Basalt Implant Center (IBIC)** / **Ibragimov Clinic** / «Международный центр базальной имплантации доктора Ибрагимова». Логотип — «Ibragimov».
- Текущий движок: **1C-Bitrix** (шаблон `/local/templates/main/`, `/upload/iblock/…`, `/bitrix/cache/…`). Разработчик — агентство **Belberry** (ссылка в футере). ### 2.2 Типографика

- В CSS указан **Montserrat**, но шрифт фактически **не подключён** (в `document.fonts` его нет) → браузер рисует Arial/Helvetica. В новом сайте **подключить Montserrat по-настоящему** (self-host, woff2, кириллица, 400/500/700) — или осознанно выбрать другой (обсудить с заказчиком; скриншоты сейчас выглядят как Arial).
- Базовый `html { font-size: 14px }` на 1359px, размеры в rem, сетка масштабируется через медиазапросы.
- Утилитарные классы (на 14px root):

| Класс | Размер / вес / line-height | Использование |
|---|---|---|
| `h1` | 42px / 700 / 1.04 | H1 страниц, hero |
| `h2` | 28px / 700 / 1.25 | Заголовки секций (зелёные) |
| `h3` | 21px / 700 | цены «от 3000 ₽», заголовки карточек |
| `h4` | 15.75px / 700 | названия услуг в списках |
| `h5_b` | 14px / 700 | жирный текст |
| `h5_p`, `h5_i` | 14px / 400 | обычный текст / курсив |
| `h6` | 12.25px / 400 | мелкий текст |
| `h7_r`, `h7_b` | 15.75px / 500 | теги-фильтры, ссылки |
| `h7_i` | 10.5px / 400 / italic | подписи («Контактный номер», «График работы») |

Курсив используется для подписей над значениями (График работы, Адрес, Электронная почта).

### 2.3 Формы, радиусы, тени

- Радиусы: **21px** — основной (карточки, секции, изображения); **10.5px** — кнопки, инпуты, маленькие карточки; **42px** — крупные контейнеры; 50% — круглые кнопки-стрелки слайдеров.
- Тени: мягкие, большие, с лёгким сиренево-голубым оттенком (`0 20px 60px rgba(120,120,180,.15)` ориентировочно) — у карточек врача, hero-карточки, инпутов.
- Контейнер: max-width ≈ **1150px** (82rem), центрирован. Секции чередуют фон white / `#F5F5F5`, многие серые секции — это скруглённые плашки внутри контейнера, а не full-width.
- Вертикальные отступы секций: `py-120` / `pb-120` (≈120px на десктопе), внутри — `py-56`, `pb-56`.

### 2.4 Кнопки

- **Primary (тёмная)**: фон `#313131`, белый текст 14px/700, padding ≈ 13px 35px, radius 10.5px. «Записаться на прием», «Записаться», «Подробнее», «Оставить заявку».
- **Outline-pill (маленькая)**: белый фон, обводка `--brand` 1px, radius ~10px, текст 12px. «Показать все», «Показать всех».
- **Белая на тёмном**: «Позвонить» в нижней плашке услуги.
- **Тег/чип**: мелкие обводные чипы для фильтра услуг (`services__tag-link`), активный — залитый `--brand` с белым текстом (на /doctors/ «Все»).
- **Стрелка ↗** в правом нижнем углу карточек (серая, на hover — тёмная).
- **Круглые стрелки слайдера** ‹ › — белый круг с тенью, иконка `--brand`.

### 2.5 Иконки

Почти все иконки — inline SVG в `background-image: url("data:image/svg+xml,…")` (стрелки, плюсы, галочки, соцсети, календарь, конверт, геометка, очки «Версия для слабовидящих»). Иконки преимуществ: `/upload/adv-1.svg` (лампочка), `adv-2.svg` (зуб), `adv-3.svg` (палец вверх). В новом проекте: перерисовать как SVG-компоненты (например, Lucide + 3 кастомных), скрипт также выгружает data-URI SVG в файлы.

## 10. Импорт картинок

### 10.1 Почему скриптом
- Сайт ленится через **lozad** — реальный путь часто в `data-src`/`data-background-image`, а не в `src`. Простое «Сохранить страницу» половину не возьмёт.
- Bitrix отдаёт уменьшенные копии `/upload/resize_cache/iblock/<xxx>/<W>_<H>_1/<hash>.jpg`. Оригинал обычно лежит по `/upload/iblock/<xxx>/<hash>.jpg` — скрипт пробует оригинал, при 404 берёт resize-версию.
- Иконки — data-URI SVG в CSS, их нужно извлечь и сохранить как `.svg`.
- Имена файлов — хэши, надо осмысленно переименовать и привязать к контенту.

### 10.2 Как запускать
Скрипт `scrape-assets.mjs` запускается **на локальной машине** (нужен доступ к ibic.clinic):

```bash
npm i -D playwright sharp
node scrape-assets.mjs          # → ./scraped/
```

Что делает:
1. Обходит все URL из п. 1 (+ находит новые по ссылкам внутри домена) в Playwright Chromium, на **двух ширинах**: 1440 и 390 (мобильные кропы могут отличаться); прокручивает страницу до низа, чтобы lozad всё подгрузил.
2. Собирает: `img[src|srcset|data-src]`, `source[srcset]`, `[data-background-image]`, `background-image` из computed style, `og:image`, favicon, ссылки Fancybox (`a[href$=.jpg]` и т.п.), data-URI SVG.
3. Для каждой картинки сохраняет **контекст**: страница, CSS-селектор секции (`main-slider`, `gallery`, `doctors`…), alt, ближайший заголовок, размер на экране.
4. Скачивает оригинал (с фолбэком), складывает в `scraped/raw/`, дедуп по SHA-1.
5. Генерирует оптимизированные версии через sharp: WebP + AVIF, ширины 480/960/1600 (не больше оригинала), в `scraped/optimized/<section>/<slug>-<w>.webp`.
6. Пишет `scraped/manifest.json` (+ `manifest.csv` для ручной проверки) и делает полностраничные скриншоты `scraped/screens/<page>-<w>.png` — эталон для сверки вёрстки.
7. Дополнительно сохраняет тексты секций в `scraped/text/<page>.json` (отзывы, образование врача, описания услуг) — чтобы не перепечатывать.

### 10.3 Дальше в проекте
- Claude Code по `manifest.json` раскладывает файлы в `public/images/{promo,gallery,services,doctors,equipment,licenses,ratings,icons,decor}/` с понятными именами (`equipment/medit-i700.webp`, `doctors/ibragimov.webp`) и прописывает пути в `content/*.json`.
- Логотип `/upload/logo-new.svg` — взять SVG как есть, поправить `alt`.
- Логотипы Яндекс/2ГИС/Zoon — лучше взять официальные из их брендбуков, а не со старого сайта.
- Скрытые картинки шаблона (`share-*`, `sharing1.png`, видео-превью) — исключить (в манифесте `hidden: true`).
- **Права**: фото клиники/врачей/лицензий принадлежат клиенту — подтвердить, что их можно использовать (особенно если фото делал фотограф по договору с Belberry). Стоковые фото в карточках услуг — проверить лицензию или заменить.

### 10.4 Мобильная версия
В этом разборе нет мобильных скриншотов. Скрипт снимает 390px — Claude Code должен открыть `scraped/screens/*-390.png` и описать мобильные паттерны (бургер, порядок колонок, слайдеры по 1 карточке) перед вёрсткой.
